> 公众号稿。图片需要手动上传（公众号不让外链），位置我都标了「配图」。

每天对着终端和编辑器写代码，我总想有点背景声。City Pop 尤其配深夜。

所以我把之前那个 Godot 城市游戏里的**车载电台**，搬进了日常在用的 DeepSeek Harness（下面简称 DSH）—— 现在它就挂在我聊天窗口的**右侧栏**里：左边跟 AI 说话，右边是一条夜路，路灯一盏盏往后跑，月亮挂在天上，电台在放歌。

## 在 DSH 里怎么装

这个插件已经发到 npm 了，包名 **`dsh-radio-dock`**。

**方式一：桌面版（推荐，三步）**

1. 打开 DSH 侧栏的「**插件**」，点「**添加插件**」，填 `dsh-radio-dock`，确认
2. **重启一次 DSH**（界面部分要重启才加载）
3. 右侧栏点「**+**」，选「**车载电台**」

**方式二：命令行**（非桌面 profile）

```powershell
dsh plugin --profile <你的 profile> add dsh-radio-dock
```

注意：**桌面版的 profile 由应用自己独占管理，命令行加不进去**，桌面版请走方式一。

**方式三：从源码**

```powershell
git clone https://github.com/lemonhall/dsh-radio-dock
```

然后在「插件」里添加这个本地目录。

装完**不需要任何配置**：它默认走你本机的代理（`127.0.0.1:7897`）去取频道和音频流；没有代理也能用，只是部分境外台会慢。

## 顺手说点实现

- **DSH 的右侧栏本身就是个"apps 入口"**：官方的「文件 / 终端 / 浏览器」三个 tab，和第三方插件走的是**完全同一套机制**。我做的只是往里面又加了一个座位 —— 这意味着你想到的任何东西（一个看板、一个日历、一台电台）都能挂进去。
- 场景是 **three.js**：路面是一块 96 段的网格，每帧按一条"三个正弦叠加"的曲线把顶点横向推过去，所以**路是真的在弯**，不是贴图在飘；路灯、护栏、车流都按同一条曲线摆位，世界是自洽的。
- **音频不让浏览器直连**：很多公共电台是 `http` 流，而页面是本地 `http`，浏览器会拦混合内容；所以频道目录和音频流都经过宿主中转，顺便把 CORS 也解决了。
- 这台电台原本是我在 Godot 里做的城市游戏（`godot_citys`）的一部分，带一个 C++ + FFmpeg 的播放后端；移植到浏览器时**那个后端整个不需要了** —— `<audio>` 就够了。

## 已知限制

- 频道是公共目录 + 公共流，**可用性不保证**，有的台会挂、会限流
- 没做「当前播放曲目」（多数公共流不带元数据）
